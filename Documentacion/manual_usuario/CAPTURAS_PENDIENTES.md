# Capturas pendientes

Cada fila del manual busca un archivo por su nombre exacto. Guarda la imagen en `Documentacion/manual_usuario/img/` con ese nombre (PNG). No hace falta indicar en qué página va: el generador la inserta donde el capítulo la cita.

El nombre sigue `CC-NN-descripcion.png`: `CC` es el capítulo y `NN` el orden dentro del capítulo.

Puedes generar el PDF aunque falten fotos. El hueco muestra **Captura pendiente** y el nombre del archivo. Al volver a generar, el recuadro se sustituye por la imagen.

Abre también `dist/capturas.html` después de generar: son las mismas fichas, marca cuáles ya tomaste y avisa si un archivo de `img/` no coincide con ningún nombre (un error de tipeo).

Formato recomendado para todas, salvo que la ficha diga otra cosa: vertical, 1080×2340, o Chrome con las herramientas de desarrollador en **iPhone 14** sobre [https://app.craftquestai.com](https://app.craftquestai.com). Tema oscuro de la app. Recorta barras del sistema si puedes. No incluyas datos personales reales: usa una cuenta de prueba.
